Cada subpasta usa o id do projeto: taskflow, clima-agora, devblog, fintrack, quizmaster ou shoplite.

Adicione uma ou mais imagens dentro da pasta do projeto e registre os caminhos em imagens, no arquivo src/data/dadosProjetos.js.
Exemplo: imagens: ['assets/projetos/taskflow/tela-01.png', 'assets/projetos/taskflow/tela-02.png']
Com uma imagem, aparece apenas a imagem. Com duas ou mais, aparecem os controles de navegacao.
